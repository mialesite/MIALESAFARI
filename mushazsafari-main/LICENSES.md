# Image licences

Every photograph served by this site ships from `public/images`. 109 files, 16.8 MB total. `src/lib/media.json` is the machine-readable registry the site renders from, and `/credits` shows the same record.

Regenerate this file with `node tools/build-licenses.cjs`.

The encoder that produced the current files is not in the repository, so re-encoding the operator archive means
re-adding the originals. See the missing-provenance note at the end.

## Missing provenance

Before any of those 72 are reused off this site, confirm the operator's written permission covers that use, or replace them.
